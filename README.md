# Reading the Wall — sources for the book

Reading the Wall is a technique handbook for indoor bouldering, typeset
with Typst. This repository holds everything you need to revise and
rebuild the PDF.

## Rebuild

```sh
./build.sh
```

This regenerates the illustrations and the source map
(`book/src-map.typ`), then compiles
`Bouldering Technique Handbook.pdf` and the exercises booklet,
`Reading the Wall - Exercises.pdf`. Both are stamped "Draft" with the
commit SHA, plus "-dirty" if there are uncommitted changes.

You need `python3` (the standard library is enough) and `typst`
(`brew install typst`). On the first build, Typst downloads the `tiaoma`
package, which draws the QR codes. To check pages visually, turn them into
images with `pdftoppm` (`brew install poppler`).

## Editions

The book is published in editions. Each edition is an annotated git tag
(`edition-1`, `edition-2`, …). Its PDF prints the edition, the date and the
commit SHA on the back of the title page, so you can trace any copy to its
exact source.

1. Make your changes and record them under "Unreleased" in
   `CHANGELOG.md`: errata with page numbers, then what was added, changed
   and removed.
2. Rename "Unreleased" to the new edition, e.g. "Second edition
   (edition-2)", and add a fresh, empty "Unreleased" above it. Update the
   edition, version and date in `CITATION.cff` and the edition and year in
   the README's citation. Then commit everything.
3. Run `./release.sh N "Second edition"`. The title is used for the tag
   message and the release, and it defaults to "Edition N". The script
   needs the GitHub CLI (`gh`). It stops if the tree is dirty, if the tag
   already exists, if the changelog has no section for the edition, or if
   rebuilding the figures and the source map changes tracked files.
   Otherwise it:
   - tags the commit `edition-N`;
   - builds the stamped PDF and the exercises booklet into `editions/` and
     copies them to `Bouldering Technique Handbook.pdf` and
     `Reading the Wall - Exercises.pdf`;
   - pushes the branch and the tag;
   - publishes a
     [GitHub release](https://github.com/simongray/ReadingTheWall/releases)
     with both PDFs attached and the changelog section as its notes.

The PDFs aren't committed: each one is attached to its release, and
`editions/` only keeps local copies.

## Web edition

The same sources also build a website, with one page for each chapter, grade
guide and technique:

```sh
./build-site.sh                  # the working tree
./build-site.sh --ref edition-2  # a published edition, from its tag
./build-site.sh --serve          # build it, then serve it on localhost
```

It needs `python3` and `typst`, like the PDF, and writes to `site/`, which
isn't in git. Add `--base-url https://…` when you build a site to publish, since
canonical links, the sitemap and the picture for shared links need its address.
A draft asks search engines not to index it.

Nothing in `book/` changes for the website, so edits to the book reach it without
extra work. `website/build.py` copies the book to a temporary folder, runs the
same generators as `build.sh` and puts `website/template.typ` in place of
`book/template.typ`. Typst's HTML export then compiles the chapters to one long
semantic HTML file, which `website/book.py` splits where print starts a new page.
Typst still marks its HTML export as experimental, and the site was last built
with Typst 0.15. In dark mode the browser loads a second copy of each figure, which
`website/dark.py` makes from the first, so a redrawn figure needs no extra work.

The build tells you when a later edition needs something from `website/`:

- **A new field on `technique`** appears under a plain label until you add it to
  `website/template.typ`.
- **A new macro in `book/template.typ`** keeps its text but loses its look until
  you add it to `website/template.typ`.
- **A sentence that only makes sense in print**, such as one about page numbers,
  gets reported. Add its web wording to `website/wording.json`.

A technique you merge into another keeps its address: add its old key to
`book/key-alias.typ` as usual, and its old page forwards to the new one.

## Layout

| Path | What it is |
|---|---|
| `book/main.typ` | The entry point, which sets the order of parts and chapters |
| `book/template.typ` | Page design and macros: `technique(...)` entries, `tref` cross-references, `ix` index terms, `src` citations, the generated tables (A–Z, category tables, techniques per grade) and the index |
| `book/chapters/` | One file per chapter. `00-front.typ` is the title page and introduction, and `10-appendices.typ` puts together the appendices from the `a-*.typ` files |
| `book/figures/` | Generated SVG illustrations (don't edit them; regenerate them) |
| `book/assets/` | Fixed images: the official CC BY-SA 4.0 badge from the Creative Commons press kit |
| `book/src-map.typ` | Generated by `tools/merge_sources.py`: maps citation keys that point at the same source onto one key |
| `book/key-alias.typ` | Technique keys that were merged into another entry |
| `book/exercises.typ`, `book/chapters/x-problems.typ` | The exercises booklet: eight problems to read, each question on a right-hand page with its answer overleaf |
| `tools/book_pages.py` | Writes `book/book-pages.json`, the book's pages for the booklet's references into it (`tref` and `bref`) |
| `tools/check_booklet.py` | Checks that each of the booklet's questions starts a right-hand page with its answer overleaf, and that every reference into the book resolved |
| `book/edition.typ` | Reads the edition, date and commit that `build.sh` and `release.sh` pass to Typst |
| `figtools/climb.py` | The drawing library: a clothed mannequin climber (back and side views, anatomical joint limits, `warn()` pose checks), holds, volumes, walls, arrows, block arrows, labels, dotted outlines of hidden parts (`XRAY`), multi-panel figures (`combine`) and film strips (`filmstrip`) |
| `figtools/authored.py` | The hands in every close-up, written point by point as outlines and drawn with the climbers' smoothing and pen, and the figures most of them appear in |
| `figtools/hand.py` | The frames, edges and walls of the hand close-ups |
| `figtools/closeup.py` | Helpers for shoes seen from above and small edges in profile, used by `figs_feet.py` |
| `figtools/figs_*.py`, `legend.py` | The figures for each chapter; each module defines `build(out)` |
| `figtools/paint.py` | Colours the finished figures, keeping each shape's panel grey; `research/COLOUR.md` has the reasons |
| `figtools/build_all.py` | Runs `legend.py` and every `figs_*.py` module, which it finds by name, then `paint.py` |
| `tools/merge_sources.py` | Finds duplicate sources across the research source lists and writes `book/src-map.typ` |
| `tools/add_gloss.py` | Adds glossary entries and keeps the glossary sorted |
| `tools/contact_sheet.py` | Renders all the figures of a module into labelled contact sheets for checking |
| `tools/colour_chart.py` | Makes a test chart for checking the figures' colours on a real e-reader |
| `tools/check_hands.py` | Builds the figures and checks every hand as drawn against `research/hand-proportions.md`: its thickness, lengths and body, its nails and its line weights. `build.sh` runs it last |
| `tools/check_alt.py` | Checks `book/figure-alt.toml`, the drawings' text descriptions: lists figures with no description, descriptions whose figure is gone, and figures whose grey drawing has changed since they were described, so a change of colour alone doesn't count |
| `research/*.md` (letters A–G) | The research dossiers the chapters were written from, each with its full source list |
| `research/*-sources.yml` | Bibliography entries (Hayagriva format), one file per dossier |
| `research/BRIEF.md`, `STYLE.md`, `KEYS.md` | The research brief, the chapter-writing guide (voice, plain language, hold-direction convention) and the master list of technique keys |
| `research/ILLUSTRATION.md`, `STREAMLINE.md`, `TYPOGRAPHY.md` | The guides for figure editing, the streamlining pass and the typography pass |
| `research/hand-proportions.md` | The proportions the hand close-ups are drawn to, as ratios with their sources |
| `research/factcheck-*.md`, `figreview-*.md`, `figcritic-*.md`, `streamline-*.md`, … | Logs of what each editing pass checked and changed |
| `FOLLOW-UPS.md` | Open questions and ideas for a later revision |
| `CHANGELOG.md` | Errata and changes between editions |
| `release.sh` | Publishes an edition: tags it, stamps the PDF and publishes it as a GitHub release |
| `build-site.sh`, `website/` | Builds the web edition: its Typst template, the page generator, the stylesheet and the script |
| `editions/` | Local copies of the published PDFs (not in git) |

## Common edits

- **Change a technique's text or grade:** edit its `#technique(...)` block
  in the chapter file. The category tables, the A–Z list and the
  per-grade lists follow automatically.
- **Add a technique:** add a `#technique(...)` block with a new `key`, and
  refer to it elsewhere with `#tref("key")`.
- **Change an illustration:** edit the pose in the chapter's
  `figtools/figs_*.py`, then run `python3 figtools/build_all.py`. You give
  a pose as hand and foot positions on the wall in centimetres, and the
  library works out the elbows and knees. The build prints a `warn()`
  message for each limb that can't reach its hold and each joint angle a
  body can't make, so a clean build prints none. To check a module
  visually, run `python3 tools/contact_sheet.py figs_feet /tmp/sheets`. It
  needs `rsvg-convert` and ImageMagick (`brew install librsvg imagemagick`).
- **Add a source:** add an entry to the dossier's `research/*-sources.yml`
  and cite it with `#src("KEY")`. Then run `python3 tools/merge_sources.py`,
  which `build.sh` also runs.

## How to cite

Gray, S. (ed.) (2026). *Reading the Wall: A technique handbook for indoor
bouldering*. Written by Claude (Anthropic). Second edition.
https://github.com/simongray/ReadingTheWall

To pin down the exact text, add the commit printed on the back of the
title page of your copy; the book's own colophon gives the full citation
with it. GitHub's "Cite this repository" button builds its citation from
`CITATION.cff`, which names the editor and Claude. The book is edited by Simon
Gray and written by Claude (Anthropic). Claude also wrote the code that draws
the figures and builds the website.
